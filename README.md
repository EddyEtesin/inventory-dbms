# Inventory DBMS

A multi-tenant inventory database management application.

## Core principles

- Multi-tenant architecture
- Organization-level data isolation
- Inventory tracked by item and location
- Stock ledger is the source of truth
- Inventory mutations are transactional
- Stock transactions are append-only
- Role-based access control
- Industry-specific extensions
